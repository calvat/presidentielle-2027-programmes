# Documents de tiers

Ce dossier accueille uniquement les documents dont la conservation et la redistribution ont été examinées et sont autorisées pour l’usage prévu. Aucun document n’est encore collecté.

Pour chaque document, créer un sous-dossier portant son identifiant et une notice `README.md` selon `modeles/document-source.md`. La notice doit identifier précisément les fichiers couverts, leur auteur, leur provenance, les droits applicables et leurs obligations. Conserver les mentions d’origine. Si les droits ne sont pas établis, créer une notice avec le lien original, sans copie du document.

Les documents ne sont pas placés sous CC0 par leur inclusion dans le dépôt. Les adaptations doivent être identifiées et examinées selon les conditions de la source. Une copie ou une conversion de format n’efface pas les droits d’origine.
